# MM ZenMusic Tool
### Misfit Mercenaries — DayZ Cassette Tape Manager

A command-line tool for managing custom cassette tapes for the [Zen's Music](https://steamcommunity.com/sharedfiles/filedetails/?id=3412251200) DayZ mod. Add new tapes, download audio directly from YouTube, convert to OGG, check for duplicates, and export all required server files — all from one menu.

---

## Features

- **Add tapes** individually or in bulk via CSV
- **Build a CSV from a raw YouTube URL list** — paste links, get titles and durations fetched automatically
- **Download audio from YouTube** automatically using `yt-dlp`
- **Convert to OGG** at the correct format for DayZ using `ffmpeg`
- **Auto-fetches duration** from YouTube so you don't have to time tracks manually
- **Import from an existing config.cpp** — bootstrap your song list from a file you already have
- **Duplicate detection** — catches same YouTube URL or similar song names
- **Renumbers OGG files** automatically when you delete a slot
- **OGG slot repair** — fix misaligned OGG files by shifting them up or down by any number of slots
- **Exports `config.cpp`** with all three required sections (`CfgVehicles`, `CfgSoundShaders`, `CfgSoundSets`) in sync
- **Exports `Collectible.json`** for the Expansion Market trader, auto-sized to your current song count
- **Exports `mm_music_types.xml`** for DayZ types, auto-sized to your current song count
- **Export all server files at once** — config.cpp, Collectible.json, and types.xml in one step

## Requirements

**Python 3.7+**

Install the Python dependency:
```
pip install yt-dlp
```

Install ffmpeg and add it to your PATH:
- **Windows:** `winget install ffmpeg` (then restart your terminal)
- **Linux/macOS:** `sudo apt install ffmpeg` / `brew install ffmpeg`

## Setup

1. Clone or download this repo
2. Place `mm_music_tool.py` next to your `MMMusic` mod folder:

```
your_folder/
├── mm_music_tool.py
├── mm_songs.json          ← created automatically on first run
├── Collectible.json       ← generated by the tool
├── mm_music_types.xml     ← generated by the tool
└── MMMusic/
    ├── config.cpp
    └── data/
        ├── song1.ogg
        ├── song2.ogg
        └── ...
```

3. Run the tool:
```
python mm_music_tool.py
```

**First run:** if no `mm_songs.json` exists, the tool will ask whether to start fresh or import from an existing `config.cpp`. Point it at your config and it will parse everything in automatically.

### Adding a single tape
Choose **option 2**. Enter the display name, description, and a YouTube URL. The tool fetches the duration automatically and asks if you want to download the track immediately.

### Bulk importing from a CSV
Choose **option 5** first to generate a blank `mm_bulk_import.csv` template, then fill it out:

```csv
name,desc,dur,yt
Pantera - Walk,Hell yeah,,https://www.youtube.com/watch?v=...
Slayer - Raining Blood,Hell yeah,,https://www.youtube.com/watch?v=...
Tool - Sober,Hell yeah,285,
```

- Leave `dur` blank if you have a YouTube URL — duration is fetched automatically
- Leave `yt` blank if you're providing the OGG file yourself — fill in `dur` manually
- Lines starting with `#` are treated as comments and ignored

Then choose **option 3** to import. The tool previews all tracks before committing, fetches missing durations, and offers to download everything in one go.

### Building a CSV from a YouTube URL list
Got a list of raw YouTube links from Discord or a playlist? Choose **option 4**.

Create a file called `mm_url_list.txt` next to the script with one URL per line:
```
https://youtu.be/abc123
https://www.youtube.com/watch?v=xyz456
# lines starting with # are ignored
```

The tool fetches the title and duration for each link via yt-dlp, cleans up noise like `(Official Video)` and `[Lyrics]`, writes a ready-to-import CSV, and offers to import it straight away.

### Downloading tracks
- **Option 9** — download or re-download a single slot. If no YouTube URL is set, it will ask for one.
- **Option 10** — batch downloads all slots that have a YouTube URL but no OGG file yet.

Audio is downloaded at best available quality and converted to OGG (Vorbis, quality 6, 44.1kHz stereo).

### Checking for duplicates
**Option 8** runs two checks:
- **Same YouTube video ID** — catches duplicate URLs even if formatted differently
- **Similar display names** — normalises and compares names to catch things like "Metallica - One" listed twice

### Removing a tape
**Option 7** removes the slot and automatically renumbers all OGG files on disk to keep slots contiguous (e.g. removing slot 10 renames `song11.ogg → song10.ogg`, `song12.ogg → song11.ogg`, etc.), then regenerates `config.cpp`.

### Importing from an existing config.cpp
**Option 16** lets you parse any existing `config.cpp` and load all its songs into the tool. You can either replace your current list or append only songs that aren't already there. Useful if your `mm_songs.json` gets lost or you're taking over someone else's mod.

### Repairing OGG slot alignment
**Option 17** shifts all OGG files from a given slot onwards up or down by any number of positions. Use this if OGG files end up misaligned with the song list — for example if an extra file was inserted at a slot, pushing everything after it off by one.

When prompted:
- **Starting from slot** — the first slot that needs to move
- **Direction** — `u` to shift to higher numbers, `d` to shift to lower numbers
- **Shift by** — how many slots to move (usually `1`)

### Exporting server files
- **Option 12** — writes `config.cpp` to the `MMMusic/` folder
- **Option 13** — writes `Collectible.json` for the Expansion Market trader
- **Option 14** — writes `mm_music_types.xml` for DayZ types
- **Option 15** — exports all three files at once. Use this after any batch of additions

## File Structure

Your song list is saved to `mm_songs.json` alongside the script. Each entry stores:

| Field | Description |
|-------|-------------|
| `name` | Display name shown in-game on the cassette |
| `desc` | Short description shown in-game |
| `dur` | Track duration in seconds (used for `playSeconds`) |
| `yt` | YouTube URL (stored as a comment in config.cpp, used for downloading) |

OGG files are stored as `MMMusic/data/song1.ogg`, `song2.ogg`, etc. Slot number = file number = class number — they must stay in sync. The tool handles renumbering automatically for most operations.

---

## Packing the Mod

After adding your tapes, run **Export ALL server files** (option 15), then pack your mod as normal using the DayZ Tools addon builder. Make sure your file list includes `*.ogg`.

## Notes

- This tool is built for the **Misfit Mercenaries** server but works with any ZenMusic mod setup — just adjust the class prefix in the script if needed (`MM_Cassette_Song` → your prefix)
- YouTube downloading is for personal/server use. Respect copyright and only use tracks you have rights to
- The tool requires an internet connection to fetch durations and download tracks
